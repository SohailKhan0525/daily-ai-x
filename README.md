# Daily AI X

Automated daily trend-to-X bot.

## Goal

Once per day, discover interesting AI/dev/tech conversations, use Gemini to research and write a concise original X post, then publish it automatically.

## Current status

🚧 Initial setup. Publishing is disabled until credentials and a safe test run are configured.

## Security

Never commit API keys, cookies, passwords, or X session data. Use GitHub Actions secrets.
